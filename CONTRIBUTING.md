# Contributing to Lex Raptor

Contributions are accepted under AGPL-3.0-only. You keep your copyright. Sign your commits with `git commit -s` to certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/). No assignment of copyright or broad relicensing permission is requested.

Use synthetic examples or properly attributable public opinions in tests. Do not contribute client documents, API keys, private benchmark tasks, commercial headnotes, proprietary citator data, model weights without rights, or confidential outputs. Third-party code must retain compatible license notices.

Run the relevant tests described in README.md, lint changed Python code, and build the web app for interface changes. Explain behavior, verification and material limits in the change description. Legal-data and retrieval changes should include provenance and evaluation effects; do not relabel a development fixture as an untouched holdout.

Paid services may coexist with the open application. Contributions must preserve local operation without a paid account, source/data export, and access to corresponding source. Report suspected privacy/security issues privately to a project maintainer once a public contact is established; never include secrets in a public issue.
