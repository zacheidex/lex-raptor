# Lex Raptor governance

Lex Raptor's purpose is to make useful legal research independently runnable and inspectable. These are the initial maintainer commitments, not a claim that a foundation or elected board already exists.

- License first-party application code under **AGPL-3.0-only**. Keep local inference, retrieval, data import/export, source review and provider adapters in the public codebase.
- Accept contributions under the same license with developer sign-off. Contributors retain copyright; no copyright-assignment CLA is required. A future commercial relicensing cannot assume ownership of others' contributions.
- Keep portable source releases, lockfiles, reproducible benchmarks, migration scripts and data-provenance manifests available. Never put private matters, credentials or third-party model weights into a release.
- Propose material architecture, licensing, data-policy and business-model changes in public issues once a repository is published. Establish independent maintainers and a documented succession process as contributors join.
- Sell optional services on their merits. Do not add a remote license check, expiration mechanism, or mandatory paid account to local operation.
- Users may fork, redistribute and run released versions under the license. A purchaser can acquire a company, brand, assets or copyrights actually owned by that company; the AGPL is not an acquisition prohibition.

The owner has authorized public release of the application source and a public project website at lexraptor.com. Releases exclude credentials, private matter data and private build instructions. There is no legal entity, independent foundation or elected council established by this project. Formation, brand stewardship and independent governance remain owner decisions. Existing release rights follow [AGPL section 2](https://www.gnu.org/licenses/agpl-3.0.html), subject to compliance; network source obligations are in section 13.
