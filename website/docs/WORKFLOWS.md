# A first expedition

Start with **Auto task** and describe what you need. Lex Raptor infers the research format, relevant sources and jurisdiction where possible, and asks for essential missing context. Open the task menu to choose a format yourself or use a direct tool without AI. **Refine** holds jurisdiction, source, date and search-term overrides; its count marks active overrides. Choose **Use automatic settings** to clear them.

1. **Brief a case:** enter `Brief Celotex Corp. v. Catrett, 477 U.S. 317 (1986)`. Resolved authorities appear before synthesis. Try `304 U.S. 64` with **Auto task → Find a case** for a model-free Erie lookup. Ambiguous names require a choice of decision/citation/date.
2. **Research an issue:** try `When does an insurer have a duty to defend a complaint alleging covered and excluded conduct?` Missing jurisdiction can trigger a focused question. Use **Refine → Jurisdiction** for state/federal, court and date overrides. Follow-ups preserve them. Explicit source choices and actual retrieval are shown separately.
3. **Review evidence:** click a finding/citation for its excerpt, quotation highlight, full opinion and real source page markers. Copy a citation or quote. **Check citations** resolves cases and runs AI support review, with reviewed passages/reasons. Partial or unreadable support stays explicit. A statute identifier such as `Alabama Code § 13A-3-23 (2024 edition)` identifies the provision and edition, not present validity.
4. **Collect cases:** choose **Auto task → Collect cited cases**, then paste `477 U.S. 317, 106 S. Ct. 2548; 304 U.S. 64; 477 U.S. 317; 1 H. 150; 999 U.S. 999; Id. at 321.` Or attach a public brief with selectable text. Parallel/repeated references group together; ambiguity, missing records and short forms stay visible. Pick/correct matches, select cases, download ZIP/CSV/individual files. The manifest retains unfinished entries. Generated HTML is labeled; original PDFs appear only when available through permitted access. Scans need OCR or pasted citations.
5. **Save a project:** choose **Save project**, name it and **Save here**. Add notes/bookmarks and explicitly save again after changes. Projects survive reload in this browser, without device sync. Reopen/rename/delete through **Projects & notes**; export/import JSON for backup. Original attachment files are excluded, but saved excerpts may contain document information.
6. **Export:** DOCX/text/JSON preserve the displayed review state, citations, source links and incomplete sections. The case collection has its own ZIP/CSV. Google Scholar links open a manual case-law search; Lex Raptor does not scrape Scholar or claim comprehensive treatment review.

The discreet **Demo** badge in the sidebar opens the **$10 expedition budget** explanation. This is a shared lifetime allowance, not per user. Source search and collection remain available when AI credits run out. Local Ollama uses no paid model calls; selected online databases still receive queries. Upload/save actions explain their actual data flows.

Stop cancels future work at server checkpoints; in-flight calls may finish and charge. Missing-section actions let you inspect more evidence or attach readable text instead of filling gaps from memory.
