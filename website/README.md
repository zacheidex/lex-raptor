# Public project website

This static site introduces Lex Raptor and links to the public source repository and local setup guide. It does not connect to the local API, Ollama, private documents, authentication, or a model provider.

Copy `index.html`, `style.css`, and `site.js` to a static site's public directory. Add the unchanged owner logo from `apps/web/public/lex-raptor-logo.png` as `logo.png`, `LICENSE`, and the corresponding source archive generated by `scripts/package_source.py` as `lex-raptor-source.tar.gz`. No environment secrets or server runtime are required.

The owner approved a public project website and public GitHub repository. Research remains in the account-free local installation. The custom domain is lexraptor.com, registered through Porkbun.
