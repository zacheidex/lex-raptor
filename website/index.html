MEASURED, WITH LIMITS

A working prototype.
An honest evaluation.

A 15-task development diagnostic used Qwen3:14b on 12 public opinions. These are engineering measurements, not an attorney-grade accuracy score or a comparison with commercial legal products.

8 / 11answerable tasks cited every expected case
37 / 48raw quotations matched a selected passage exactly
3 / 3unsupported or current-validity questions abstained
7.49 smedian measured task latency on an RTX 4090

Matching a quote does not prove the conclusion.

The quotation gate removed 11 propositions. Retained answers still included support errors, such as dropping an explicit exception in Erie. Subsequent treatment and current legal validity are not checked. Independent attorney evaluation remains outstanding.

Local requirements
Python 3.11+, Node 20.9+, Docker, uv, and Ollama. The default model download is about 9.3 GB. A smaller local model may suit other hardware; performance will differ.
